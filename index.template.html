使用说明与编辑方法

离线手册，不连接模型、不保存账号，也不执行模板命令。

怎样最快用起来？

  1. 搜索要做的事，选与当前阶段相符的模板。
  2. 填写参数；黄色占位符表示仍需替换的内容。
  3. 复制中文或英文，粘贴到目标项目的会话。
  4. 核对目录、授权和验收，再发送。

两种语言意图相同，一次发一种即可。可删减会话里已经确认的背景；重要边界和成功标准应保留。

这些模板能承诺什么？

它们明确目标、上下文、执行边界和验证要求。未对 216 条逐条做模型效果 A/B 测试，不承诺一次成功；工具权限、网络和资料仍会影响执行。

工作目录不会自动赋予服务或云端写入权限。模板涉及提交、推送、重启或云文档写入时，请确认这就是你要授权的动作。

精选与来源怎样处理？

公开版本不包含原始聊天摘录、会话标识、具体服务器 IP 或账号凭据。模板经过参数化改写，不等同于历史原句。

带 SSH 参数的模板统一要求按给定地址直连。

参数与收藏保存在哪里？

模板和搜索在本地运行。填写值只保留在当前打开期间；项目、SSH 和环境会作为本次通用默认值，切换模板后仍可修改。

收藏保存在当前浏览器。换浏览器、换位置或清理数据后可能丢失。导出收藏只包含模板原稿，不含你填写的参数。

什么时候要补充资料？

跨会话、跨机器任务请提供可访问的具体路径和目标。截图、错误原文、样本与期望结果通常比重复催促更有帮助。

不要在手册填写密码、私钥或 API token；让执行工具通过已有授权方式读取所需凭据。提示词不能凭空赋予工具能力。
